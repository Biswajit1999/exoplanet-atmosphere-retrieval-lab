# Conditional spectral robustness (29 October 2026)

This independent Python calculation reuses the **355 released Carter et al. JWST spectral bins** already pinned in `data/wasp39b_benchmark.json`. It does **not** repeat the browser's bounded H2O/CO2 amplitude grid: it fits an **unbounded linear basis** with per-product offsets, log-wavelength slope, and the same three illustrative Gaussian feature templates. Negative fitted feature coefficients are allowed, so its estimates are **not directly equivalent** to the browser's nonnegative-grid posterior.

Three distinct checks are implemented: (1) QR/SVD-based full-rank generalized least squares with conditional Fisher errors and reduced chi-square; (2) deletion of each instrument/order product to reveal sensitivity to wavelength coverage and offsets; (3) within-product AR(1) correlation sensitivity at ρ=0, 0.3 and 0.6, with products kept independent. Index-lag correlation is a **hypothetical** covariance, not a measured JWST calibration product. This assumes Gaussian marginal errors and fixed Gaussian feature shapes. It does not model wavelength-dependent opacities, inter-product covariance, stellar contamination, or radiative transfer.

Reproduce using `python -m pip install numpy matplotlib`, `python -m unittest discover -s tests -p 'test_spectral_robustness.py' -v`, and `python scripts/run_spectral_robustness.py --output results/spectral_robustness.json --plot results/spectral_robustness.png`. Tests use seeded synthetic data; the runner uses the committed, DOI-attributed real spectrum. **No molecular abundance or detection significance can be inferred** from these conditional errors, especially because the baseline reduced χ² is already substantially above unity. No new observational data were collected.
